# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in MessageBrokerEngine, please report it
privately through **GitHub Security Advisories**:

https://github.com/Mendl-Labs/MessageBrokerEngine/security/advisories/new

Please do **not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests, and please do not email a personal address — the
Security Advisories flow above is the only supported channel and keeps the
report private until a fix is available.

We will acknowledge new reports as quickly as possible and keep you informed as
the issue is triaged and resolved.

## Supported Versions

This project is deployed continuously from the `main` branch. Only the latest
build is supported; there are no maintained long-term-support branches.
